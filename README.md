# Gapi - Site de Randonnée

Gapi est un site web moderne et responsive dédié aux amateurs de randonnée. Il présente une sélection de chemins de randonnée à travers la France, avec des informations détaillées, des photos et un système de contact.

## Structure du Site

Le site est composé de plusieurs pages :

1. **Accueil (index.html)**
   - Présentation générale
   - Sections mises en avant
   - Appel à l'action

2. **Randonnées (randonnees.html)**
   - Liste des randonnées disponibles
   - Filtres par difficulté, durée et distance
   - Cartes détaillées pour chaque randonnée

3. **Galerie (galerie.html)**
   - Photos des différentes randonnées
   - Filtres par catégorie
   - Visionneuse d'images

4. **Contact (contact.html)**
   - Formulaire de contact
   - Informations de contact
   - Carte interactive

## Fonctionnalités

- Design responsive adapté à tous les appareils
- Menu de navigation avec version mobile
- Filtres de recherche pour les randonnées
- Galerie photo interactive
- Formulaire de contact fonctionnel
- Animations et transitions fluides

## Installation

1. Clonez le dépôt :
```bash
git clone [URL_DU_REPO]
```

2. Ouvrez le fichier `index.html` dans votre navigateur pour voir le site.

## Personnalisation

Pour personnaliser le site :

1. Modifiez les images dans le dossier `images/`
2. Ajustez les couleurs dans `styles.css`
3. Modifiez le contenu dans les fichiers HTML
4. Personnalisez les fonctionnalités dans `script.js`
